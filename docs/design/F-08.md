## 2. Componentes del Módulo `secrets` (`miku-agent`)

### 2.1 Backend de Almacenamiento Criptográfico (`SecretStoreBackend`)
- **[`WindowsCredentialBackend`](file:///C:/Users/cxmluwu/Desktop/miku-project/miku/crates/miku-agent/src/secrets/backend.rs):** Implementación de producción para Windows.
  - Almacena bajo el prefijo `miku/secrets/{alias}` con tipo `CRED_TYPE_GENERIC = 1` y persistencia `CRED_PERSIST_LOCAL_MACHINE = 2`.
  - Invoca `CredWriteW`, `CredReadW`, `CredDeleteW` y `CredFree` exportados por `Advapi32.dll`.
  - Si el alias no existe, mapea `ERROR_NOT_FOUND (1168)` a `Ok(None)` de forma segura sin pánicos.
- **[`EncryptedMemoryBackend`](file:///C:/Users/cxmluwu/Desktop/miku-project/miku/crates/miku-agent/src/secrets/backend.rs):** Implementación portable en memoria para entornos de CI / no-Windows y pruebas unitarias aisladas sin tocar el registro del sistema operativo.

### 2.2 Protección de Memoria y Zeroización (`Zeroize` / `Zeroizing<T>`)
- Proporciona borrado seguro de memoria impidiendo que el optimizador de Rust elimine la limpieza:
  ```rust
  pub trait Zeroize {
      fn zeroize(&mut self);
  }
  ```
  Implementado mediante `std::ptr::write_volatile` sobre cada byte seguido de `std::sync::atomic::compiler_fence(Ordering::SeqCst)`.
- El tipo RAII `Zeroizing<T>` implementa `Deref`, `DerefMut` y `Drop`. Al caer fuera de alcance, llama automáticamente a `zeroize()`.
- Implementación segura de `Debug`: formatea como `"[REDACTED_SECRET]"` y no implementa `Display` para bloquear impresiones accidentales en consola o trazas.

### 2.3 Gestor Centralizado (`SecretManager`)
- **Autorización Previa Gatekeeper:** `get_secret_authorized(alias, session_token)` valida en primer lugar el token de sesión (`constant_time_token_eq`) y el alias; inmediatamente somete la solicitud a evaluación pre-ejecución en `GatekeeperEngine`. El almacén persistente (Credential Manager) o la caché en memoria **solo se consultan tras un veredicto `Allow`**. Si Gatekeeper emite `Deny` o `AskPending`, o si el token es inválido, jamás se llama a `load_secret` ni se puebla la memoria.
- **Caché Caliente:** Tras una autorización exitosa y primera lectura, retiene una copia en `HashMap<String, Zeroizing<Vec<u8>>>`, logrando latencias de lectura de **25 a 35 microsegundos** (< 1.0 ms presupuesto).
- **Rotación Atómica:** `rotate_secret(alias, new_secret)` zeroiza inmediatamente la entrada previa en caché, guarda el nuevo valor en Credential Manager y actualiza la marca temporal en el catálogo de metadatos.
- **Borrado Seguro:** `delete_secret(alias)` elimina la credencial en Windows, purga y zeroiza la memoria caché y remueve el registro del catálogo.
- **Listado Seguro:** `list_summaries()` serializa exclusivamente `Vec<SecretSummary>`, donde cada elemento contiene únicamente `{ alias, provider, status }`.

## 3. Comandos de la CLI (`miku-cli secret`)

Se provee gestión local sin exposición de claves en argumentos, historial o logs:

- `miku-cli secret list [--json]`: Imprime la tabla o JSON con `{ alias, provider, status }`.
- `miku-cli secret get <alias>`: Devuelve únicamente `{ alias, provider, status }`.
- `miku-cli secret set <alias> --provider <provider> [--model <model>] [--json]`:
  - **Prohibición de `--value`:** Se rechaza tajantemente `--value <secret>` en argumentos CLI para impedir fugas en árboles de procesos (`Get-Process`), historial de shell (`PSReadLine`, `.bash_history`) o logs.
  - **Entrada interactiva oculta fail-closed:** Solicita la clave mediante terminal interactiva (`STDIN`) con eco desactivado a nivel de consola Win32 (`SetConsoleMode` sin `ENABLE_ECHO_INPUT`). Si `SetConsoleMode` falla o no logra desactivar el eco (incluyendo entornos Unix sin supresión de eco), **aborta de forma cerrada sin leer ni un solo byte de entrada**. Restaura siempre el modo original mediante RAII (`ConsoleModeGuard`) y limpia el buffer temporal mediante RAII (`ZeroizingLineBuffer`).
  - **Fail-safe en no-interactivo:** Si no se detecta una terminal interactiva (p. ej. scripts headless o pipes), falla de forma segura explicando el requisito.
  - **Respuesta acotada:** La respuesta de éxito imprime únicamente `{ alias, provider, status }`.
- `miku-cli secret delete <alias>`: Elimina la credencial del almacén cifrado.
