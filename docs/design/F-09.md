## 1. Arquitectura de Ahorro de Tokens (F-09)

El subsistema `token_saver` de `miku-agent` introduce tres barreras deterministas antes y durante cada turno del `AgentHarness`:

```text
Entrada del usuario (user_prompt, force_llm)
   │
   ├──► [1. LocalIntentRouter] (0 tokens, 0 llamadas HTTP, 0 lecturas de SecretManager)
   │       ├─ Saludos casuales ("hola", "buenos días", "gracias") ──► LocalZeroTokenReply (0 tokens)
   │       ├─ Comandos internos ("/help", "/status", "/budget", "/agents", "/models") ──► LocalZeroTokenReply (0 tokens)
   │       ├─ Consultas de estado local (hora/fecha, batería/energía, agentes, gasto diario) ──► LocalZeroTokenReply (0 tokens)
   │       ├─ Override explícito (`force_llm = true` o prefijo `/llm `, `!llm `, `@llm `) ──► ForwardToLlm (ExplicitForceLlm)
   │       └─ Entrada ambigua, técnica, multi-intención o con rutas/código/shell ──► ForwardToLlm (sin falsos positivos)
   │
   ├──► [2. DailySpendTracker::evaluate_pre_flight] (ANTES de leer API keys o abrir sockets)
   │       ├─ Sincroniza día actual mediante `DailyClock` (`InjectableDayClock` / `SystemUtcDayClock`) y reinicia gasto si cambió el día
   │       ├─ Si el proveedor es gratuito/local (`LlmProvider::Ollama` o `is_free_or_local = true`) ──► Allowed (0 costo)
   │       ├─ Si `spent_micros >= 100%` del límite diario del proyecto ──► BlockedHardCap (bloquea antes de SecretManager y red; devuelve `FallbackAlternative`s gratuitas/locales)
   │       └─ Si `80% <= spent_micros < 100%` ──► Allowed + emite `BudgetWarningAlert` (80 %)
   │
   └──► [3. Ensamblado con Prefijo Estable KV-Cache + Contabilidad Post-Turno]
           ├─ Reutiliza `StaticSystemPrefix` y `SystemPromptAssembler` de `miku-memory` (Paso 1.6)
           ├─ Fija el bloque `[STATIC_SYSTEM_PREFIX v1]` (directivas + herramientas ordenadas alfabéticamente desde `ToolRegistry`) idéntico byte a byte al inicio del payload JSON
           └─ Extrae `usage` explícito del proveedor o estima tokens con `miku_memory::estimate_tokens` y actualiza el ledger diario con `ModelPricingRate` configurable
```

## 2. Ruteo Local 0-Token y Prevención de Falsos Positivos (`local_router.rs`)

- **Categorías resueltas localmente (`LocalRouteCategory`):**
  1. `CasualGreeting`: saludos breves y confirmaciones (`hola`, `hola miku`, `buenos días`, `buenas tardes`, `gracias`, `thanks`, `ok`, `listo`).
  2. `InternalCommand`: comandos internos seguros de solo lectura (`/help`, `/ayuda`, `/status`, `/estado`, `/budget`, `/presupuesto`, `/gasto`, `/agents`, `/agentes`, `/models`, `/modelos`, `/version`, `/ping`).
  3. `LocalStatusQuery`: consultas locales deterministas sobre `LocalSystemSnapshot` (hora/fecha actual, modo de energía y porcentaje de batería, número de agentes activos y gasto diario del proyecto).
- **Guardas contra falsos positivos:**
  - Cualquier entrada de más de 96 caracteres, multilínea, o que contenga caracteres de código/shell (`` ` ``, `;`, `|`, `&`, `>`, `<`, `{`, `}`, `[`, `]`, `=`, `\`) o marcadores técnicos (`.rs`, `.toml`, `.ts`, `src/`, `crates/`, `cargo `, `git `, `fn `, `bug`, `error`, `fix`, `refactor`, `test`, `por qué`, `cómo `, `explica`, `lee `, `ejecuta`, etc.) se deriva inmediatamente a `RouteDecision::ForwardToLlm`.
  - Si un saludo va acompañado de una instrucción técnica (ej. `"hola, revisa el bug en src/main.rs"`), el clasificador detecta los marcadores técnicos y deriva al LLM sin falso positivo local.
- **Override explícito (`force_llm`):**
  - El usuario o llamador puede forzar explícitamente el envío al LLM mediante `execute_turn_with_options(prompt, true, cancel)` o anteponiendo `/llm `, `!llm ` o `@llm ` (ej. `"/llm hola"`), siempre que el presupuesto diario del proyecto no haya alcanzado el 100 %.
- **Seguridad y Gatekeeper:**
  - `LocalIntentRouter` opera únicamente sobre un `LocalSystemSnapshot` en memoria de solo lectura. No ejecuta herramientas (`fs_read`, `fs_write`, `shell_exec`, `browser_action`, `memory_query`) ni puentea jamás `GatekeeperEngine`.

## 3. Prefijo Estable para Caché KV (`prefix_cache.rs`)

- **Reutilización estricta del paso 1.6 (`miku-memory`):**
  - `build_static_system_prefix_from_registry(agent_id, soul_directives, registry)` recorre `ToolRegistry::list_deterministic()` (respaldado por `BTreeMap` en orden alfabético canónico) y construye un `miku_memory::StaticSystemPrefix`.
  - `assemble_turn_prompt_with_stable_prefix` delega directamente en `miku_memory::SystemPromptAssembler::assemble_within_budget`.
  - `format_provider_request_with_stable_prefix` inyecta `prefix.rendered_block()` como primer mensaje inmutable del payload del proveedor. Aunque cambien los fragmentos RAG FTS5, los chunks adicionales o el historial entre turnos, los bytes iniciales del prefijo de sistema y herramientas permanecen idénticos bit a bit (`StaticSystemPrefix::verify_prefix_stability(&assembled) == true`).

## 4. Control de Gasto Diario por Proyecto, Umbrales 80 % / 100 % y Fallbacks (`budget.rs`)

- **Tarifas configurables (`ModelPricingRate`):**
  - No se inventan precios de proveedores. Cada tarifa se configura explícitamente en micro-unidades (`micros`, donde `1_000_000 = $1.00`) por cada 1.000 tokens de entrada no cacheados (`input_micros_per_1k`), entrada cacheada (`cached_input_micros_per_1k`) y salida (`output_micros_per_1k`), usando división entera con redondeo hacia arriba (`div_ceil(1_000)`).
- **Umbral de aviso (80 %) y bloqueo duro (100 %):**
  - Al alcanzar o superar el 80 % (`warning_threshold_pct = 80`), `DailySpendTracker` emite `BudgetWarningAlert` y lo registra en `AgentHarness::last_budget_warning`.
  - Al alcanzar el 100 % (`hard_cap_pct = 100`), `evaluate_pre_flight` devuelve `PreFlightBudgetDecision::BlockedHardCap` **antes** de invocar `call_model_with_key_rotation`. En consecuencia, `SecretManager::get_secret_authorized` no se invoca (`authorized_read_attempts` no incrementa) y no se abre ningún socket TCP/WinHTTP.
- **Alternativas gratuitas o locales (`FallbackAlternative`):**
  - Cuando `BlockedHardCap` bloquea una llamada paga, devuelve alternativas gratuitas/locales configuradas (por defecto `Ollama Local (qwen2.5-coder:7b, 0 costo)` en `http://127.0.0.1:11434/api/chat` y `Modo comandos/consultas locales (0 tokens)`).
  - `AgentHarness::switch_to_fallback_alternative(&alt)` permite conmutar inmediatamente al proveedor gratuito/local, el cual es permitido por `evaluate_pre_flight` (`is_free_or_local: true`) con costo `0` y sin leer claves de pago.
- **Reinicio diario determinista (`DailyClock`):**
  - El trait `DailyClock` permite inyectar `InjectableDayClock` en pruebas o `SystemUtcDayClock` en producción. Cuando `current_day_key()` cambia (ej. de `"2026-03-31"` a `"2026-04-01"`), `DailySpendTracker` reinicia automáticamente `spent_micros`, los contadores de tokens y las banderas de alerta del proyecto.
