# F-16 — Push-to-Talk (PTT) y Transcripción STT Local Bajo Demanda (Paso 4.1)

## 1. Objetivo y Alcance
Implementar la captura de micrófono estrictamente acotada a la pulsación activa del hotkey global de Push-to-Talk (`Alt+Space`, `DEFAULT_PTT_HOTKEY_COMBO`) y la transcripción local bilingüe (español `es` / inglés `en`) bajo demanda, entregando el texto resultante a la cola de la sesión activa del agente con **0 llamadas de red**, **0 tokens de proveedor consumidos**, **0 handles de dispositivo abiertos en reposo** y **0 MB de modelo residente tras expirar el TTL de inactividad**.

## 2. Decisiones Arquitectónicas Aplicadas
- **ADR-008 (Voz Local Bajo Demanda):**
  - El modelo acústico-espectral local (`MKSTT01\0`, formato versión `1`) no se incluye en el instalador base ni se precarga al arrancar (`< 1000 ms` cold start intacto).
  - Si el archivo `.mkstt` no existe en disco dentro de la jaula `CanonicalPathJail`, `inspect_model_availability()` y `release_ptt_and_transcribe_to_session()` devuelven un estado tipado (`SttModelAvailability::Missing { download_card }` / `PttPipelineOutcome::ModelMissing { download_card }`) con `model_id`, `version`, `expected_size_bytes`, `expected_sha256_hex` y `requires_explicit_user_action: true`.
  - La descarga (`download_and_verify_model_explicit`) exige confirmación explícita (`user_confirmed == true`), autorización de `GatekeeperEngine` para `Capability::Network` y `Capability::FsWrite`, y verificación en memoria de longitud exacta + hash `SHA-256` en tiempo constante (`constant_time_token_eq`) antes de escribir de forma atómica (`.mkstt.part` -> `.mkstt`).
- **ADR-005 (Gatekeeper y Kill Switch Global):**
  - La apertura del micrófono requiere `Capability::Input` (`microphone:ptt_capture`) y verifica `!gatekeeper.is_kill_switch_active()`.
  - La carga perezosa del modelo requiere `Capability::FsRead` dentro de `CanonicalPathJail`.
  - Si el Kill Switch se activa (`trip_kill_switch_and_purge`), se cierra de inmediato el stream de captura, se sobrescriben con `0` los buffers PCM del dispositivo y de `VoiceInteractionController`, se descargan y ponen a cero los pesos del modelo STT (`allocated_model_bytes() == 0`) y se vacía la cola de órdenes de voz.

## 3. Módulos y Contratos (`miku/crates/miku-ui/src/voice/`)
1. `stt_engine.rs`:
   - `SttLanguage` (`Es`, `En`), `SttModelManifest`, `SttModelDownloadCard`, `SttModelAvailability`, `SttModelError`.
   - `redact_sensitive_voice_diagnostic`: redacta literales entrecomillados (transcripciones), arreglos de muestras PCM `[...]`, claves `sk-*` y tokens `Bearer`/`eyJ*`.
   - `synthesize_bilingual_command_pcm` y `extract_utterance_feature_vector`: síntesis determinista de trayectorias de formantes a `16 kHz` mono `PCM16` y extractor espectral Goertzel de 24 dimensiones.
   - `verify_and_parse_stt_model_bytes` y `OnDemandLocalSttRuntime`: verificación `SHA-256`, inferencia local sin red y descarga automática por TTL (`poll_ttl` / `unload_and_zero`).
2. `capture_devices.rs`:
   - Trait `PttAudioCaptureStream` (`open_capture_stream`, `read_captured_pcm_chunk`, `stop_and_close_stream`, `is_stream_open`, `active_stream_handles_count`, `retained_device_buffer_bytes`).
   - `DeterministicFixtureCaptureDevice`: dispositivo determinista con inyección de fallos y zero-fill verificable en `stop_and_close_stream()` y `Drop`.
   - `WinMmWaveInCaptureProbe`: sonda real Win32 (`winmm.dll`: `waveInGetNumDevs`, `waveInOpen`, `waveInReset`, `waveInClose`) que garantiza `0` handles abiertos al cerrar o en entornos CI sin micrófono físico.
   - `VoiceAgentSessionOrder` y `VoiceSessionOrderQueue`: cola FIFO de órdenes transcritas por sesión activa.
3. `ptt_pipeline.rs`:
   - `PttSttOrchestrator<C: PttAudioCaptureStream>`: coordina `VoiceInteractionController`, `GatekeeperEngine`, `CanonicalPathJail`, `OnDemandLocalSttRuntime`, `VoiceSessionOrderQueue` y `WebView2IpcBridge` (`MikuLinkMessageV1::Command` con `action: "voice_enqueue_prompt"`).
4. `tests_ptt_stt.rs`:
   - Suite TDD `LEDGER-4.1-1..7` cubriendo ciclo de vida PTT, limpieza ante errores/cancelación/Kill Switch, transcripción bilingüe ES/EN, `0` llamadas de red / `0` tokens, verificación `SHA-256` fail-closed, tarjeta de descarga + TTL a `0 MB` y redacción de diagnósticos.
